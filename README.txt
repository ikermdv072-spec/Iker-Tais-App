Control de Gastos

Como usar este sitio:

1. Sube esta carpeta a Vercel como sitio web estatico.
2. Abre la web publicada.
3. En "Conexion Supabase", pega:
   - Project URL
   - Anon public key
   - Nombre de tabla, por ejemplo expenses
   - Clave para Atajos, una palabra secreta que solo tu conozcas
4. Usa el enlace ejemplo para crear el Atajo de iPhone.

Notas:

- Esta version guarda los gastos en el navegador.
- La seccion Supabase deja anotados los datos para la siguiente etapa.
- Para guardar realmente en Supabase, falta crear la tabla y conectar la web a la base de datos.
